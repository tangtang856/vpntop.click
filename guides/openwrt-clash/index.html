OpenWrt 路由器安装 OpenClash 插件打造全屋翻墙软路由：保姆级教程

📅 更新时间：2026年11月 💻 适用环境：路由器与旁路网关 ⏱️ 阅读时长：约 5-8 分钟实操
💡 教程导读与核心目的

在软路由上部署代理，是实现全家人手机、电视盒、游戏机免装软件全自动翻墙的最优雅方案。OpenClash 是目前 OpenWrt 生态最成熟的插件。

图文实操步骤分解

第一步：在 OpenWrt 安装依赖与 OpenClash IPK

通过 LuCI 界面上传 luci-app-openclash.ipk，或在终端通过 opkg update && opkg install 安装对应依赖并更新 Mihomo 核心。

第二步：创建配置文件并导入机场订阅

进入【服务】->【OpenClash】->【配置文件订阅】，添加新配置，填入订阅链接并保存更新。

第三步：运行模式选择【Fake-IP (TUN)】并启动

在通用设置中将模式选为 Fake-IP (TUN)，开启【本地 DNS 劫持】，保存并应用。全屋连接该 Wi-Fi 的设备即可直接无感访问外网。

常见报错排查技巧 (Troubleshooting)

1. 节点全部超时或 Ping 为 Timeout： 首先检查电脑或手机的【系统时间】是否精确对齐网络标准北京时间。时间偏差超过 90 秒会导致 TLS 握手彻底失败。其次检查订阅链接是否已过期或流量耗尽。

2. 能打开 Google 但微信图片加载不出来： 说明误开启了【全局代理 (Global)】模式。请在代理设置中切换回【规则 (Rule)】模式，让国内流量自动绕过代理走本地直连。

3. 提示 Port already in use 端口被占用： 通常是由于旧的客户端后台进程没有退出彻底，或与其他加速器冲突。在任务管理器中结束对应进程，或在设置中将端口从 7890 修改为 7892 即可解决。
