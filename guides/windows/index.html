Windows 电脑机场客户端配置教程：Clash Verge Rev 保姆级实操

📅 更新时间：2026年11月 💻 操作系统：WINDOWS ⏱️ 阅读时长：约 5 分钟实操
💡 教程导读

Windows 平台目前最受推荐的现代化客户端是基于 Mihomo 内核的 Clash Verge Rev。界面优雅，内存占用低，完美支持智能分流与系统代理模式。

图文实操步骤分解

第一步：获取可靠的开源客户端安装包

建议直接从 GitHub 官方发布页下载 Clash Verge Rev 的 64位 Windows 安装包（.exe 或便携免安装版本）。切勿在未经核实的第三方下载站下载，以防植入木马。

第二步：复制服务商订阅链接

登录您的机场后台，在仪表盘找到【便捷导入】或【订阅链接】，复制专属的 Clash / Clash.Meta 订阅 URL。

第三步：导入订阅并更新节点

打开 Clash Verge Rev，点击左侧【订阅 (Profiles)】，在顶部输入框粘贴订阅 URL，点击【保存/导入】。软件将自动拉取最新的节点列表与分流规则。

第四步：选择规则分流模式与主力节点

进入左侧【代理 (Proxies)】页面，模式推荐选择【规则 (Rule)】，这样访问国内网站（百度、淘宝、B站）将直连不消耗流量，访问海外受限网站自动走代理。选择延迟低于 50ms 的香港或日本节点作为主力。

第五步：开启系统代理 (System Proxy)

在主界面右下角或【设置】中勾选【系统代理】开关，即可畅享高速海外网络加速。

常见报错排查技巧 (Troubleshooting)

1. 节点全部超时或 Ping 为 Timeout： 首先检查电脑或手机的【系统时间】是否精确对齐网络标准北京时间。时间偏差超过 90 秒会导致 TLS 握手彻底失败。其次检查订阅链接是否已过期或流量耗尽。

2. 能打开 Google 但微信图片加载不出来： 说明误开启了【全局代理 (Global)】模式。请在代理设置中切换回【规则 (Rule)】模式，让国内流量自动绕过代理走本地直连。
