Surge for Mac 增强模式与网关旁路路由配置：打造终极工作站

📅 更新时间：2026年11月 💻 适用环境：桌面端系统 ⏱️ 阅读时长：约 5-8 分钟实操
💡 教程导读与核心目的

Surge for Mac 是 macOS 生态中最成熟稳定的网络工具。开启网关模式后，它能直接充当旁路由为手机、电视和主机提供局域网免翻代理。

图文实操步骤分解

第一步：安装 Surge Mac 并激活

从 Surge 官网下载 DMG 镜像，安装并授权系统扩展组件（System Extension）。

第二步：导入托管订阅配置

点击菜单栏 Surge 图标，进入【偏好设置】->【配置】->【安装托管配置】，粘贴订阅并同步。

第三步：勾选【增强模式 (Enhanced Mode)】

开启增强模式后，Mac 上的所有 TCP/UDP 流量、后台命令行工具与 Docker 均自动完成透明代理分流。

常见报错排查技巧 (Troubleshooting)

1. 节点全部超时或 Ping 为 Timeout： 首先检查电脑或手机的【系统时间】是否精确对齐网络标准北京时间。时间偏差超过 90 秒会导致 TLS 握手彻底失败。其次检查订阅链接是否已过期或流量耗尽。

2. 能打开 Google 但微信图片加载不出来： 说明误开启了【全局代理 (Global)】模式。请在代理设置中切换回【规则 (Rule)】模式，让国内流量自动绕过代理走本地直连。

3. 提示 Port already in use 端口被占用： 通常是由于旧的客户端后台进程没有退出彻底，或与其他加速器冲突。在任务管理器中结束对应进程，或在设置中将端口从 7890 修改为 7892 即可解决。
