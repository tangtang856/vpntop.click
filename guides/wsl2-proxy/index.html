Windows WSL2 子系统共享宿主机 Clash 代理网络配置实战教程

📅 更新时间：2026年11月 💻 适用环境：进阶开发者环境 ⏱️ 阅读时长：约 5-8 分钟实操
💡 教程导读与核心目的

WSL2 采用独立的 Hyper-V 虚拟化架构，其内部与宿主机不在同一个网络命名空间。掌握正确的网关转发配置是每个在 Windows 上做开发人员的必备功底。

图文实操步骤分解

第一步：在 Windows 端客户端开启【允许局域网连接】

确保 Clash Verge 的 Allow LAN 开启，这样 WSL2 虚拟网卡才能访问宿主机的 7890 端口。

第二步：在 ~/.wslconfig 开启 Mirrored 镜像网络（Windows 11 首选）

在 Windows 用户目录下编辑 .wslconfig，写入 [experimental] networkingMode=mirrored，重启 WSL 后直接共享宿主机 127.0.0.1 端口。

第三步：旧版系统通过脚本获取宿主机网关 IP

如果使用的是旧版 Windows 10，在 ~/.bashrc 中提取 /etc/resolv.conf 中的 nameserver 作为宿主机 IP 自动注入 http_proxy 即可。

常见报错排查技巧 (Troubleshooting)

1. 节点全部超时或 Ping 为 Timeout： 首先检查电脑或手机的【系统时间】是否精确对齐网络标准北京时间。时间偏差超过 90 秒会导致 TLS 握手彻底失败。其次检查订阅链接是否已过期或流量耗尽。

2. 能打开 Google 但微信图片加载不出来： 说明误开启了【全局代理 (Global)】模式。请在代理设置中切换回【规则 (Rule)】模式，让国内流量自动绕过代理走本地直连。

3. 提示 Port already in use 端口被占用： 通常是由于旧的客户端后台进程没有退出彻底，或与其他加速器冲突。在任务管理器中结束对应进程，或在设置中将端口从 7890 修改为 7892 即可解决。
