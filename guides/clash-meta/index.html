Clash Meta (Mihomo) 内核规则分流与高级设置详解

💡 教程导读与核心目的

Mihomo（原 Clash.Meta）是目前开源社区最强大、维护最活跃的分流代理内核。掌握其高级配置能彻底杜绝 DNS 泄漏并极致优化访问速度。

图文实操步骤分解

第一步：理解 Rule-Providers 动态规则集

通过引入外部 YAML 规则文件（如 Loyalsoldier 或 ACL4SSR），可以让国内顶级域名、Steam 游戏加速和 AI 服务走不同的指定策略组。

第二步：配置 fake-ip 与 DNS 防污染

将 dns.mode 设置为 fake-ip，并配置境外 DoH（如 Cloudflare 1.1.1.1 或 Google 8.8.8.8），有效规避运营商 DNS 投毒并缩短首包响应时间。

第三步：针对 ChatGPT 与 Claude 的专项路由策略

为 OpenAI 相关域名单独设立策略组，强制指定具有原生住宅 IP 的美国或新加坡节点，避免随意漂移触发风控。

常见报错排查技巧 (Troubleshooting)

1. 节点全部超时或 Ping 为 Timeout： 首先检查电脑或手机的【系统时间】是否精确对齐网络标准北京时间。时间偏差超过 90 秒会导致 TLS 握手彻底失败。其次检查订阅链接是否已过期或流量耗尽。

2. 能打开 Google 但微信图片加载不出来： 说明误开启了【全局代理 (Global)】模式。请在代理设置中切换回【规则 (Rule)】模式，让国内流量自动绕过代理走本地直连。

3. 提示 Port already in use 端口被占用： 通常是由于旧的客户端后台进程没有退出彻底，或与其他加速器冲突。在任务管理器中结束对应进程，或在设置中将端口从 7890 修改为 7892 即可解决。
