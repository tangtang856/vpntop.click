Sing-box macOS 平台配置指南：命令行与图形界面深度调优

📅 更新时间：2026年11月 💻 适用环境：桌面端系统 ⏱️ 阅读时长：约 5-8 分钟实操
💡 教程导读与核心目的

Mac 开发者偏爱高效的系统服务。Sing-box 在 macOS 上通过 launchd 作为系统后台守护进程运行，能够提供极其沉浸且不占用状态栏空间的透明代理。

图文实操步骤分解

第一步：选择图形版或命令行安装

新手推荐使用 SFM (Sing-box for Mac) 图形客户端，高阶极客可通过 brew install sing-box 通过终端配置。

第二步：配置 config.json 出站规则

将机场给出的配置导入，在 inbound 中开启 mixed 混合协议端口（如 7890）或配置 tun 虚拟网卡。

第三步：验证终端与浏览器网络畅通

在终端输入 curl -I https://google.com 确认返回 HTTP 200，说明透明代理已完全就绪。

常见报错排查技巧 (Troubleshooting)

1. 节点全部超时或 Ping 为 Timeout： 首先检查电脑或手机的【系统时间】是否精确对齐网络标准北京时间。时间偏差超过 90 秒会导致 TLS 握手彻底失败。其次检查订阅链接是否已过期或流量耗尽。

2. 能打开 Google 但微信图片加载不出来： 说明误开启了【全局代理 (Global)】模式。请在代理设置中切换回【规则 (Rule)】模式，让国内流量自动绕过代理走本地直连。

3. 提示 Port already in use 端口被占用： 通常是由于旧的客户端后台进程没有退出彻底，或与其他加速器冲突。在任务管理器中结束对应进程，或在设置中将端口从 7890 修改为 7892 即可解决。
