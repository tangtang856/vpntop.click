# 关于我们

VPN Top（vpntop.click）是一个专注于中文翻墙梯子测评、IPLC/IEPL高速专线节点监测与网络加速科普的技术媒体与测评实验室。

## 核心原则

1. **客观独立**：数据源严格取自官方公开套餐与真实网络测试，杜绝虚假跑分。
2. **数据透明**：明确标注每 GB 成本、线路架构与短板不足，供用户理性抉择。
3. **技术分享**：致力于普及现代网络代理协议知识，提升中文互联网用户的出海生产力。
