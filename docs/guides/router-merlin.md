# 华硕梅林固件安装科学上网插件打造透明代理网关实战指南

<div class="seo-badge">分类：路由器与旁路网关 · 2026最新保姆级实操</div>

::: info 核心导读
拥有华硕路由器（如 RT-AX86U、RT-AC68U）的用户，刷入梅林改版固件后无需额外购买软路由，即可单设备搞定全家科学上网。
:::


### 步骤 1：第一步：开启 JFFS 并离线安装插件

进入梅林后台【系统设置】，勾选 Format JFFS on next boot，在软件中心上传科学上网插件离线安装 tar 包。


### 步骤 2：第二步：在插件后台粘贴机场订阅

打开插件界面，选择【节点管理】->【订阅管理】，粘贴订阅链接并一键拉取所有节点。


### 步骤 3：第三步：工作模式选择【gfwlist 模式】或【大陆白名单】

推荐选择大陆白名单模式，保证国内访问原生千兆直连，海外流量自动送往代理核心。
