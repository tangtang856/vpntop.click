# Windows 电脑机场客户端配置教程：Clash Verge Rev 保姆级实操

<div class="seo-badge">分类：桌面端系统 · 2026最新保姆级实操</div>

::: info 核心导读
Windows 平台目前最受推荐的现代化客户端是基于 Mihomo 内核的 Clash Verge Rev。界面优雅，内存占用低，完美支持智能分流与系统代理模式。
:::


### 步骤 1：第一步：获取可靠的开源客户端安装包

从 GitHub 官方发布页下载 Clash Verge Rev 的 64位 Windows 安装包（.exe 或便携免安装版本）。切勿在未经核实的第三方下载站下载，以防植入木马。


### 步骤 2：第二步：复制服务商订阅链接

登录您的机场后台，在仪表盘找到【便捷导入】或【订阅链接】，复制专属的 Clash / Clash.Meta 订阅 URL。


### 步骤 3：第三步：导入订阅并更新节点

打开 Clash Verge Rev，点击左侧【订阅 (Profiles)】，在顶部输入框粘贴订阅 URL，点击【保存/导入】。软件将自动拉取最新的节点列表与分流规则。


### 步骤 4：第四步：选择规则分流模式与主力节点

进入左侧【代理 (Proxies)】页面，模式推荐选择【规则 (Rule)】，这样访问国内网站直连不消耗流量，访问海外受限网站自动走代理。选择延迟低于 50ms 的香港或日本节点作为主力。


### 步骤 5：第五步：开启系统代理 (System Proxy)

在主界面右下角或【设置】中勾选【系统代理】开关，即可畅享高速海外网络加速。
