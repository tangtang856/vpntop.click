# Steam Deck 掌机 Linux 桌面模式与游戏模式科学上网配置

<div class="seo-badge">分类：游戏主机与极客数码 · 2026最新保姆级实操</div>

::: info 核心导读
Steam Deck 拥有完整的 Arch Linux 底层系统。通过配置系统代理或 TUN 模式，你可以随时随地在掌机上刷创意工坊、看 YouTube 和联机对战。
:::


### 步骤 1：第一步：长按电源键切换到【桌面模式 (Desktop Mode)】

在桌面模式下打开 Discover 应用商店，搜索并安装 Clash Verge Flatpak 版或一键脚本。


### 步骤 2：第二步：导入订阅并开启 TUN 虚拟网卡模式

导入机场订阅，在设置中为 Clash Verge 开启系统服务模式与 TUN 模式，输入掌机 sudo 密码授权。


### 步骤 3：第三步：切回【游戏模式 (Gaming Mode)】依然生效

TUN 模式属于内核级全局代理，切换回掌机游戏主界面后依然在后台持续接管网络，Steam 社区与商店秒开。
