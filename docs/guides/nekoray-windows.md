# NekoRay / NekoBox 跨平台客户端新手配置与 TUN 模式指南

<div class="seo-badge">分类：桌面端系统 · 2026最新保姆级实操</div>

::: info 核心导读
NekoRay 基于现代的 Sing-box 与 Xray 核心开发，跨 Windows 和 Linux 平台。其开箱即用的轻量设计受到了很多极客与开发者的喜爱。
:::


### 步骤 1：第一步：解压并初次启动

下载 NekoRay 最新 zip 包，解压后双击 nekoray.exe。首次启动选择 core 为 sing-box。


### 步骤 2：第二步：导入订阅或自建节点

点击顶部【分组】->【新建分组】，类型选【订阅】，填入订阅链接并保存更新。


### 步骤 3：第三步：勾选【系统代理】与【TUN 模式】

在顶部工具栏直接勾选【TUN 模式】。客户端将自动接管所有进程流量，甚至包括无法设置独立代理的海外网络游戏。
