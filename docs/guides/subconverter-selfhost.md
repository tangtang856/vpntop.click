# 自建 Subconverter 订阅转换服务：保护隐私与节点重命名进阶技巧

<div class="seo-badge">分类：进阶开发者环境 · 2026最新保姆级实操</div>

::: info 核心导读
很多新手图方便把机场订阅贴到公共在线转换平台，极易导致专属订阅被中间人抓包爬取偷跑流量。自建私有 Subconverter 服务是保护账号安全的关键一步。
:::


### 步骤 1：第一步：理解公共订阅转换的隐私风险

第三方在线 API 可以轻易记录每一个请求的订阅 URL，一旦泄露，他人可在任何地方拉取你的节点，消耗你的流量甚至导致账号被服务商封禁。


### 步骤 2：第二步：使用 Docker 一键启动私有 Subconverter

在云服务器或本地 NAS 执行 `docker run -d -p 25500:25500 tindy2013/subconverter:latest` 即可启动私有轻量转换引擎。


### 步骤 3：第三步：通过私有 API 进行格式转换

在请求参数中直接引用 `http://localhost:25500/sub?target=clash&url=你的订阅链接`，整个过程完全在私有环境完成，0 隐私风险。
