# v2rayNG 安卓高级分流、分应用代理与自定义 DNS 调优指南

<div class="seo-badge">分类：移动端系统 · 2026最新保姆级实操</div>

::: info 核心导读
v2rayNG 是安卓平台上最具代表性的开源客户端之一。通过合理配置分应用代理与自定义路由，能大幅提升移动端续航与隐私安全性。
:::


### 步骤 1：第一步：配置【分应用代理】白名单

进入左侧抽屉菜单点击【分应用代理】，勾选需要走代理的应用（如 Chrome、Twitter、YouTube），排除微信、淘宝与各大网银。


### 步骤 2：第二步：预设自定义路由规则

将预定义规则设置为【绕过局域网及大陆地址】，避免国内域名走节点消耗流量。


### 步骤 3：第三步：配置自建 DoH 防 DNS 污染

在设置中将远程 DNS 修改为 1.1.1.1 或 8.8.8.8，杜绝运营商 DNS 劫持。
