# iOS 平台机场梯子配置教程：Shadowrocket (小火箭) 与 Loon 新手实操

<div class="seo-badge">分类：移动端系统 · 2026最新保姆级实操</div>

::: info 核心导读
受 App Store 区域政策限制，iOS 端翻墙工具需要使用美区或港区等海外 Apple ID 下载。目前生态最为成熟、普及率最高的工具是 Shadowrocket（俗称小火箭）。
:::


### 步骤 1：第一步：获取海外 Apple ID 并下载小火箭

退出 App Store 当前账号，登录海外 Apple ID（切勿在 iCloud 登录以免锁机），搜索 Shadowrocket（售价约 2.99 美元）下载安装。


### 步骤 2：第二步：导入机场订阅

打开 Safari 浏览器登录机场后台，点击【一键导入 Shadowrocket】，或者手动在小火箭首页右上角点击【+】，类型选择【Subscribe】，粘贴订阅链接完成更新。


### 步骤 3：第三步：设置全局路由为【配置 (Config)】

在小火箭底部将全局路由选为【配置】，保证大陆 IP 直连，避免国内微信和网银支付异常。


### 步骤 4：第四步：连接并信任 VPN 配置描述文件

轻触顶部连接开关，系统会弹窗提示添加 VPN 配置，输入锁屏密码授权后即可连通。
