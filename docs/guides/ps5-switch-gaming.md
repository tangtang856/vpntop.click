# PS5 与任天堂 Switch 主机游戏跨服联机代理加速实战指南

<div class="seo-badge">分类：游戏主机与极客数码 · 2026最新保姆级实操</div>

::: info 核心导读
主机游戏玩家经常遇到 Nintendo eShop 进不去、PSN 商店下载慢或《斯普拉遁》《怪物猎人》联机掉线报错。通过局域网代理即可完美解决。
:::


### 步骤 1：第一步：在电脑客户端开启【允许局域网连接 (Allow LAN)】

在电脑上的 Clash Verge 中勾选【允许局域网连接】，记下电脑的内网 IP 地址（如 192.168.1.50）和代理端口（7890）。


### 步骤 2：第二步：在 Switch / PS5 手动设置网络代理

进入主机网络设置 -> 连接 Wi-Fi -> 高级设置，将【代理服务器】设为【开启】，输入电脑的内网 IP 与 7890 端口。


### 步骤 3：第三步：连接测试验证 NAT Type 改善

在主机上运行连接测试，查看 NAT 类型是否变更为 NAT Type A 或 B，下载速度大幅拉满即可畅快联机。
