# Apple TV 4K 安装小火箭或 Sing-box 打造客厅大屏流媒体无阻访问

<div class="seo-badge">分类：大屏电视与智能家居 · 2026最新保姆级实操</div>

::: info 核心导读
苹果在 tvOS 17 引入了原生 VPN 框架，宣告了 Apple TV 必须依赖复杂旁路由的时代彻底终结。现在在电视上直接装个小火箭就能畅享 4K HDR。
:::


### 步骤 1：第一步：在 Apple TV 登录美区 Apple ID

进入系统设置添加用户，登录拥有 Shadowrocket 或 Sing-box 的海外账号，进入 App Store 即可直接下载。


### 步骤 2：第二步：利用手机局域网隔空推送订阅

打开 Apple TV 上的小火箭，在 iPhone 上通过扫码或输入电视显示的局部 IP 网址，直接将订阅一键推送到电视端。


### 步骤 3：第三步：开启代理享受 4K 秒开

点击连接，在 Apple TV 上打开 Netflix、Disney+ 或 YouTube，原汁原味 4K 杜比视界片库直接呈现。
