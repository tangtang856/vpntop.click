# Sing-box Android 手机端配置与分流教程：零卡顿轻快体验

<div class="seo-badge">分类：移动端系统 · 2026最新保姆级实操</div>

::: info 核心导读
对于低内存或老旧安卓手机，Sing-box Android 版极低的资源消耗能够显著改善日常续航，同时避免由于后台占用过高被系统频繁查杀。
:::


### 步骤 1：第一步：安装 Sing-box 官方客户端

从 Google Play 商店或 GitHub Releases 下载最新的 sing-box-android 客户端 APK 安装包。


### 步骤 2：第二步：添加远程 Profiles 订阅

点击 Profiles -> 新增配置，类型选择 Remote，粘贴机场服务商给出的 Sing-box 专属订阅 URL 并点击右上角更新。


### 步骤 3：第三步：选择节点并连接

在 Dashboard 仪表盘选择你的主力专线节点，点击连接按钮，允许创建 VPN 连接即可运行。
