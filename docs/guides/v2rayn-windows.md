# v2rayN Windows 最新版 Core 配置与 Xray 切换教程：传统老将依然强劲

<div class="seo-badge">分类：桌面端系统 · 2026最新保姆级实操</div>

::: info 核心导读
对于不喜欢花哨 UI、追求极简高效和丰富自定义参数的老玩家来说，v2rayN 依然是 Windows 平台上兼容性最强、协议支持最全的工具。
:::


### 步骤 1：第一步：下载集成 Core 的完整发布包

前往 v2rayN 官方 GitHub Releases，下载包含 Xray-core 的 v2rayN-With-Core.zip，解压即可运行。


### 步骤 2：第二步：在订阅分组中添加机场链接

点击顶部【订阅分组】->【订阅分组设置】->【添加】，输入备注并粘贴订阅链接，确认后点击【更新订阅】拉取节点。


### 步骤 3：第三步：设为活动服务器并开启自动配置系统代理

在节点列表中右键选择延迟最低的节点设为活动服务器，在底部将系统代理切换为【自动配置系统代理】，路由选【绕过大陆】。
