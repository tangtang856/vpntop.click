# Sing-box Windows 客户端图文配置完全教程：轻量新内核实战

<div class="seo-badge">分类：桌面端系统 · 2026最新保姆级实操</div>

::: info 核心导读
Sing-box 作为新一代通用网络代理框架，以极高的性能和极低的内存占用闻名。其支持的现代协议生态极其完善，是未来的主力之选。
:::


### 步骤 1：第一步：获取 Sing-box 图形客户端

推荐使用支持图形界面的 Sing-box GUI 或 Nekoray。下载解压至无中文路径的纯英文字符文件夹下。


### 步骤 2：第二步：导入包含 VLESS/Hysteria2 的订阅配置

在客户端配置栏粘贴服务商提供的 Sing-box 订阅链接，软件将自动解析出包含 direct、block 和各类代理 outbound 的完整 JSON 结构。


### 步骤 3：第三步：启用规则路由与 TUN 模式

在路由设置中确保 GeoIP 和 Geosite 规则生效，勾选开启 TUN 虚拟网卡，赋予系统级网络加速权限。
