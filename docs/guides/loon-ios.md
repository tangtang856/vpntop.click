# Loon iOS 规则分流、插件与重写脚本入门教程：玩转轻奢客户端

::: info 核心导读
Loon 以极其清爽现代的 UI、强大的插件生态和优异的性能表现在 iOS 代理圈中享有盛誉，兼具简单与高可玩性。

### 步骤 1：第一步：获取 Loon 客户端

使用海外 Apple ID 在 App Store 购买并下载 Loon（售价约 5.99 美元）。


### 步骤 2：第二步：导入订阅节点

打开 Loon，点击【配置】->【订阅】-> 右上角【+】，输入名称并粘贴机场订阅 URL，保存后轻触【更新】拉取全部节点。


### 步骤 3：第三步：配置分流策略组与一键连通

在【策略】页中，你可以为国外媒体、AI 工具（ChatGPT）、国内直连指定不同的节点组，最后在首页点击启动连接。
