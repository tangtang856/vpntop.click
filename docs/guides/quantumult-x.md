# Quantumult X (圈X) 策略组配置与节点订阅导入：极客玩家必备

<div class="seo-badge">分类：移动端系统 · 2026最新保姆级实操</div>

::: info 核心导读
Quantumult X 以强大的 JavaScript 脚本编写能力、精细化策略组调度和华丽的 UI 图表受到广大翻墙极客的热烈追捧。
:::


### 步骤 1：第一步：安装 Quantumult X

使用海外 Apple ID 登录 App Store 购买下载 Quantumult X（俗称圈X）。


### 步骤 2：第二步：引用节点资源 (Server Resource)

点击右下角风车图标进入设置，找到【节点】->【引用 (资源)】，点击右上角【+】填入机场订阅链接并勾选更新。


### 步骤 3：第三步：创建策略组与规则分流

在配置文件中引入成熟的分流规则库，在策略组中为流媒体、OpenAI 分配对应的代理策略，长按右下角大按钮开启代理。
