# Stash iOS (Clash 核心分支) 新手配置与覆写规则实战教程

<div class="seo-badge">分类：移动端系统 · 2026最新保姆级实操</div>

::: info 核心导读
如果你已经习惯了桌面端 Clash 的 YAML 规则体系，那么 Stash 就是你在 iPhone 和 iPad 上无缝迁移原有配置的最佳选择。
:::


### 步骤 1：第一步：在美区 App Store 下载 Stash

搜索 Stash 下载并完成初次打开的引导设置。


### 步骤 2：第二步：直接导入 Clash 订阅

在配置页面点击从 URL 下载，直接粘贴你电脑上正在使用的 Clash 订阅链接，Stash 原生解析 YAML 配置文件。


### 步骤 3：第三步：选择节点并开启按需连接

在首页选择想要出海的节点，可勾选【按需连接 (On Demand)】，在检测到非蜂窝 Wi-Fi 时自动决定是否开启。
