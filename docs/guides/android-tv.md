# Android TV / 索尼电视 / 小米盒子安装 Clash 电视版配置指南

<div class="seo-badge">分类：大屏电视与智能家居 · 2026最新保姆级实操</div>

::: info 核心导读
普通的手机版代理应用在电视上很难用遥控器操作。本教程针对 Android TV、Google TV 操作系统优化，手把手教你遥控器无痛操控。
:::


### 步骤 1：第一步：将 TV 专用版 APK 拷贝至 U 盘

在电脑上下载适配 Android TV 遥控器焦点操作的 Clash for Android TV 版 APK，存入 U 盘插入电视安装。


### 步骤 2：第二步：通过局域网剪贴板导入订阅

在电视应用内开启【局域网导入】，用手机浏览器扫描电视屏幕上的二维码，在手机上把订阅链接粘贴过去即可完成导入。


### 步骤 3：第三步：开启系统 VPN 授权与开机自启动

首次点击启动时同意系统的 VPN 创建申请，在设置中勾选开机自动连接，以后打开电视直接就能看海外节目。
