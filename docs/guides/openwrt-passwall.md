# OpenWrt 路由器 PassWall 插件节点分流与自动故障切换配置

<div class="seo-badge">分类：路由器与旁路网关 · 2026最新保姆级实操</div>

::: info 核心导读
相比功能繁复占用较大的 OpenClash，PassWall 更加轻量稳定，在几十元低配硬路由（如 MT7621）上也能跑出极高吞吐。
:::


### 步骤 1：第一步：在 PassWall 节点列表添加订阅

进入【服务】->【PassWall】->【节点订阅】，输入订阅地址，点击【保存并订阅】。


### 步骤 2：第二步：设定主节点与备用备选节点

在基本设置中，将 TCP 节点指定为主力专线节点（如微风网络或隐形人），备用节点指定为备用梯子，开启自动切换检测。


### 步骤 3：第三步：配置中国列表直连与 gfwlist 分流

选择 DNS 模式为 ChinaDNS-NG，国内域名国内解析，国外受阻域名走远程加密解析，彻底杜绝 DNS 污染。
